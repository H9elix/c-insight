# 自绘结果树试验分支

本说明对应 `experiment/custom-result-trees` 分支，基于正式版本 `0.22.21`。试验包保留该基础版本号，通过文件名中的 `custom-result-trees-preview` 区分；验收通过后再决定合并、正式版本号及发布。

## 范围与操作

上下文（Context）、引用（References）、调用者（Callers）、被调用者（Callees）、父类型（Supertypes）、子类型（Subtypes）、包含文件（Includes）、被包含关系（Included By）、导航历史（Navigation History）、书签（Bookmarks）、文档符号（Document Symbols）及工程诊断（Project Diagnostics）共用自绘树。符号搜索和代码预览已有独立 Webview，保持各自布局。

| 操作 | 行为 |
| --- | --- |
| 单击源码位置节点名称 | 立即更新代码预览，保持树展开状态 |
| 在配置的双击间隔内再次单击同一名称 | 在编辑器打开同一位置，保持树展开状态 |
| 单击左侧箭头 | 只展开或折叠；展开未加载分支时才查询其子项 |
| 上下方向键、Home、End | 移动选择并预览有源码位置的结果 |
| 右方向键 | 展开当前节点，或进入已展开节点的第一个子项 |
| 左方向键 | 折叠当前节点，或返回父项 |
| Enter / 空格 | 在编辑器打开 / 在代码预览显示 |
| 右键 / Shift+F10 | 显示节点对应的打开、复制引用、书签或宏展开查询菜单 |
| 视图内容顶部的全部折叠图标 | 折叠该窗口的所有分支 |
| 筛选图标 / Ctrl+F / Cmd+F | 筛选当前已展开树中的名称和描述；Escape 清空并关闭 |

没有源码位置的普通分组名称不会触发导航；其展开仍使用箭头。刷新、加载更多等操作节点继续执行自身命令。双击/Enter 打开源码后沿用随光标刷新抑制，直到主动移动编辑器光标才恢复。固定与锁定规则沿用基础版本。

## 维护边界

- `resultTreeModel.ts`：不依赖 VS Code 的展开状态、稳定行 ID、懒加载投影、定位和过时代次丢弃。
- `resultTreeView.ts`：将现有 `MutableTreeProvider` 接到 Webview，校验消息及节点菜单动作，桥接展开事件、可见性与源码导航。
- `resultTreeWebview.ts`：独立点击处理、虚拟滚动、键盘导航、ARIA 树角色、上下文菜单及本地筛选；动态文本仅通过 DOM 文本属性输出。
- `viewLifecycle.ts`：统一注册和释放上述视图，视图 ID 及原有标题栏命令保持一致。
- `treeNode.ts`：保留业务节点并合并同一节点的并发子项加载，防止程序化展开与 UI 刷新重复查询。
- `scripts/copy-webview-assets.mjs`：在构建时复制官方 Codicons 的 CSS 与字体到 `dist/codicons`，通过 VSIX 文件清单打包；许可计入第三方声明。

隐藏窗口只记录数据变更，不启动 UI 刷新或因 UI 投影而读取源码片段。分支折叠时不获取子项。只有虚拟滚动窗口内的节点才触发原有 `resolveVisible` 补充描述，避免大量结果产生后台源码读取。已有按深度展开、搜索定位和工作区调用树恢复通过统一 `reveal` 接口接入；双击导航本身不执行展开、折叠或补偿性恢复。

图标使用官方 Codicons 字体，符号颜色跟随 VS Code 颜色主题。原生树中由产品图标主题替换的自定义字形不会自动传入 Webview；本试验优先保持标准图标与主题颜色一致。屏幕阅读器树角色和键盘路径已接入，但仍需实际辅助技术验收。

## 重点验证

1. 调用者与被调用者分别测试未展开节点和已展开节点：双击只跳转，树状态不变。
2. 单击名称只预览；单击箭头只展开/折叠；重复点击和快速切换节点时目标正确。
3. 测试类型、包含、引用分组、文档符号与书签分组，确认相同交互成立。
4. 测试右键菜单、按深度展开、搜索定位、全部折叠、引用分组自动展开配置和调用树会话恢复。
5. 测试键盘、明暗与高对比度主题、中文/英文、长行横向滚动及大量结果的滚动。
6. 固定调用树/引用后浏览其他符号，确认原结果保留；双击后不立即跟随落点刷新。
7. 折叠或隐藏窗口后修改/浏览源码，确认查询仍遵循原有按需规则。

自动测试执行实际浏览器事件处理脚本以检查双击与箭头动作分离，并覆盖懒加载竞态、旧结果丢弃、重复名称、配置初始展开、定位和消息边界。Extension Host 还对真实 clangd 调用者/被调用者执行同一消息路径，验证预览、编辑器跳转和展开状态；实际鼠标手感、主题及屏幕阅读器表现仍需试验包验收。
