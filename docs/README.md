# C Insight 文档索引

文档按用途分为以下四类：

## 用户文档 `user/`

- `user-guide.zh-CN.md`：完整中文使用手册、窗口逻辑、命令和配置参考。
- `user-guide.en.md`：英文使用说明。

## 开发维护 `development/`

- `developer-guide.zh-CN.md`：中文开发者手册，包含源码文件职责、状态所有权、
  测试与发布流程。
- `architecture.md`：核心架构、数据流、信任边界和架构守卫。

## 规划设计 `planning/`

- `roadmap.md`：已完成阶段、延期功能和备忘录。
- `relationship-graph-plan.zh-CN.md`：Relationship Graph 的设计与实施方案。

## 测试验收 `validation/`

- `performance-baseline.zh-CN.md`：大型工程合成性能基准。
- `third-phase-acceptance.zh-CN.md`：性能与可靠性阶段验收报告。
- `microsoft-provider-probe.zh-CN.md`：Microsoft Provider 探测方法与 API 边界。
- `microsoft-provider-probe-result.json`：可复核的 Provider 探测结果。
- `microsoft-engine-acceptance.zh-CN.md`：Microsoft C/C++ 引擎阶段验收报告。

用户行为和配置以用户手册为准；源码维护以开发者手册及实际代码为准；规划文档中的
延期项目不表示已经实现。
