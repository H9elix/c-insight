# C Insight 0.22.16

## 中文

### 新功能

- 文档符号（Document Symbols）现在可以跟随活动编辑器的可见区域中心，并高亮包含编辑器中心行的最深层符号。
- 高亮项会自动滚动到文档符号树的可见范围内，但不会夺取键盘焦点或改变用户当前选择。
- 新增 `cInsight.documentSymbols.followEditorCenter` 配置，默认启用；关闭后文档符号树保持原有的手动浏览行为。

### 性能与行为

- 编辑器滚动使用 75 ms 防抖，并且只在文档符号窗口可见时计算中心符号。
- 匹配只读取已经加载的文档符号树，不会向 clangd 或 Microsoft C/C++ 语言服务发起额外语义查询。
- 层级式 `DocumentSymbol` 结果会选择包含中心行的最深层、最窄范围符号；平铺式 `SymbolInformation` 结果只使用提供程序返回的范围。

### 发布维护

- GitHub Release 改用仓库内版本化的中英双语说明；质量门会检查说明文件与 `package.json` 版本是否一致，并阻止缺失或含占位符的发布。

## English

### New feature

- Document Symbols can now follow the center of the active editor's visible area and highlight the deepest symbol containing the editor-center line.
- The highlighted item is revealed in the tree without stealing keyboard focus or changing the user's current selection.
- The new `cInsight.documentSymbols.followEditorCenter` setting is enabled by default; disabling it keeps the previous manual-browsing behavior.

### Performance and behavior

- Editor scrolling is debounced by 75 ms, and center-symbol matching runs only while the Document Symbols view is visible.
- Matching reads only the already loaded document-symbol tree and sends no additional semantic request to clangd or the Microsoft C/C++ language service.
- Hierarchical `DocumentSymbol` results select the deepest, narrowest symbol containing the center line; flat `SymbolInformation` results use only the range supplied by the Provider.

### Release maintenance

- GitHub Releases now use versioned, curated bilingual notes stored in the repository. The quality gate verifies that the notes match the `package.json` version and rejects missing notes or unfinished placeholders.
