# C Insight 0.22.27

## 中文

- 新增工程文件窗口，以平铺列表展示工作区文件，支持多根目录、文件名/路径/类型排序、常驻实时搜索框和一键清空。
- 高亮当前打开的文件；单击文件显示代码预览，双击或按 Enter 在编辑器打开。图片、二进制和大文件使用 VS Code 默认编辑器打开。
- 成功打开文件后自动清空搜索；焦点离开工程文件窗口时跟随当前文件，只有筛选隐藏目标时才自动清空。独立锁定按钮可暂停自动清空和滚动，同时保留当前文件高亮。
- 自动定位时尽量将高亮文件放在列表中部，首尾自然限位；同一可见文件的重复更新不会拉回手动滚动位置。
- 文件清单自动同步创建、删除和重命名，隐藏窗口时暂停扫描，普通文本编辑不重新扫描。

## English

- Added Project Files: a flat workspace inventory with multi-root support, name/path/type sorting, a persistent live search box, and one-click clearing.
- Highlight the active file; single-click to preview and double-click or press Enter to open it in the editor. Images, binary files, and oversized files open through VS Code's default editor.
- Successful opens clear the search. Following resumes outside the file view and clears a filter only when it hides the active file. An independent Lock pauses automatic clearing and scrolling while retaining active-file highlighting.
- Automatic reveal centers the highlighted file where possible, respects list boundaries, and avoids pulling back manual scrolling on repeated updates for the same visible file.
- The inventory follows file creation, deletion, and renaming, pauses scans while hidden, and skips rescans for ordinary text edits.
