# C Insight 0.22.21

## 中文

### 代码预览滚动体验

- 新目标在显示前先准备上下各一个 `cInsight.codePreview.loadBatchLines` 批次的源码，并受 `maximumLoadedLines` 限制；默认可直接获得目标上下各 50 行的滚动缓冲。
- Webview 在隐藏状态完成初始布局和 `linesBefore` 定位后再一次显示，避免选中符号后滚动条延迟出现、可见代码偏移或首次滚轮只触发加载。
- 后续源码在距离已加载边界约一个视窗时提前请求；极端快速滚动或超大视窗仍由有界的首次滚轮重放兜底，增量插入继续保留可见锚点和横向位置。

### 异步更新稳定性

- 延迟引用详情或调用数量再次发布完全相同的 URI 和目标范围时，只更新标题元数据，不再重建 `webview.html`，因此不会把已经滚动的预览重置到定义初始位置。
- 用户在代码预览内滚动或按下鼠标/触控指针后，当前预览取得代次所有权。2 秒或 10 秒后返回的声明到定义升级仍可更新其他窗口，但不能覆盖正在阅读的源码。
- 主动移动编辑器光标到新目标或执行显式刷新后，自动上下文跟随会正常恢复；代码预览锁定仍保持更高优先级。

### 文档与验证

- 中英文用户手册、交叉编译指南、架构说明、开发者手册、路线图和历史验收说明中的当前版本基线已同步为 `0.22.21`；历史 Release 和带日期的实测数字保持原始记录。
- 完整质量门覆盖编译、静态检查、65 项自动测试、双语本地化、文档一致性、链接、第三方声明和生产构建；Extension Host 冒烟测试与临时 VSIX 已完成验证。

## English

### Code Preview scrolling

- A fresh target now prepares one `cInsight.codePreview.loadBatchLines` batch on each available side before it is shown, bounded by `maximumLoadedLines`; the defaults provide a 50-line scrolling buffer in each direction.
- The Webview completes its first layout and applies the configured `linesBefore` position while hidden, then reveals the source once, avoiding delayed scrollbar changes, visible source shifts, and a first wheel gesture that only loads data.
- Later source is prefetched within one viewport of a loaded edge. Bounded first-wheel replay remains a fallback for unusually fast input or very large viewports, while incremental insertion continues preserving the visible anchor and horizontal position.

### Asynchronous update stability

- When delayed reference details or call counts republish the exact same URI and target range, Code Preview updates title metadata without rebuilding `webview.html`, so an already scrolled preview is not reset to the definition's initial position.
- A wheel gesture or mouse/touch pointer press inside Code Preview claims generation-bound ownership. A declaration-to-definition upgrade returned after 2 or 10 seconds may still update other views but cannot replace source being read.
- Deliberately moving the editor cursor to a new target or running an explicit refresh restores automatic context following; Code Preview Lock remains the stronger rule.

### Documentation and validation

- The English and Chinese user guides, cross-compilation guides, architecture, developer guide, roadmap, and current-version statements in historical validation documents now use the `0.22.21` baseline. Historical Releases and dated measurements remain unchanged evidence.
- The complete quality gate covers compilation, static analysis, 65 automated tests, bilingual localization, documentation consistency, links, third-party notices, and production construction. Extension Host smoke testing and the temporary VSIX also completed validation.

## 安装与校验 / Installation and verification

从 [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.21) 下载 `c-insight-0.22.21.vsix` 与 `SHA256SUMS`，校验后在 VS Code 中运行 **扩展：从 VSIX 安装...**。完整调用层次建议使用 clangd 20 或更高版本；Microsoft C/C++ 语言服务仍为明确选择后启用的可选引擎。

Download `c-insight-0.22.21.vsix` and `SHA256SUMS` from the [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.21), verify the checksum, and run **Extensions: Install from VSIX...** in VS Code. clangd 20 or newer is recommended for complete Call Hierarchy support; the Microsoft C/C++ language service remains an explicitly selected optional engine.
