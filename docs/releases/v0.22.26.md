# C Insight 0.22.26

## 中文

### 编译参数宏保留自身调用者

- clangd 已明确识别、仅由编译参数 `-D` 注入的数值宏、条件宏和函数别名宏，现在也能建立宏调用者根，按宏自身引用列出跨文件准确使用位置，包括 `#if` 中的使用。
- 不会默认扩大为展开后函数的全部调用。只有显式执行“查询宏展开后函数的调用者”才切换函数范围；刷新或重新查询恢复宏使用模式，源码 `#define` 对照保持原有规则。
- 没有可导航源码定义时，调用者根锚定所选使用位置，不伪造 `#define`，该使用仍作为子结果保留；未打开引用文件不为归属标签而被批量打开。

### 上下文隐藏时仍可自动刷新

- 修复条件宏在上下文折叠/隐藏时被误认为无符号、从而跳过自动刷新和引用详情的问题。
- 宏身份与上下文共享至多一次惰性悬停查询；普通同名函数保留快速路径，仅预览可见时不查关系，全隐藏时不发自动查询。既有空白保留、编辑门控、取消与显式操作规则继续生效。

### 验证与保留边界

- 用户已验收描述性临时 VSIX 后授权正式发布。完整质量检查、299 项测试（71 个套件）、主 clangd 隔离扩展宿主及编译宏专项回归通过，联网依赖审计为 0 个漏洞。专项还纳入主干 CI。
- 合成场景断言编译宏调用者分别有 2、5、1 个精确位置，以及显式展开函数的三处调用、源码宏对照、根锚点和六种受控可见性。受控控制器可见性不是所有物理鼠标、布局或 Remote 环境的完整覆盖。
- `CI-REG-049` 的调用者与自动刷新修复已验收；编译宏的异常定义位置、自动代码预览选址和工作区符号搜索边界仍未修复。数值宏的无关函数目标、函数别名的展开目标、条件宏的空定义应分别判断，不将本次发布描述为预览修复。Microsoft 宏识别能力未扩展，也不宣称覆盖其他 clangd 版本。

## English

### Preserve compiler-injected macro Caller scope

- Numeric, conditional and function-alias macros supplied only by compiler `-D` flags can now receive macro Caller roots when clangd explicitly identifies them. Callers lists their exact cross-file References, including uses in `#if` directives.
- Default results never widen to every call of the expanded function. Only **Show Expanded Function Callers** changes that scope; refreshing or requerying restores macro uses. Source `#define` controls keep their existing behavior.
- Without a navigable source definition, the root anchors at the selected use rather than an invented `#define`, and that use remains a child result. Unopened reference files are not bulk-opened merely to obtain enclosing-function labels.

### Refresh even with Context hidden

- Fixed conditional macros being mistaken for empty cursor positions when Context was collapsed/hidden, suppressing automatic updates and Reference details.
- Macro identity and Context share at most one lazy Hover. Normal matching functions keep their fast path, preview-only demand does not query relationships, and fully hidden navigation sends no automatic query. Whitespace preservation, edit gates, cancellation and explicit-action behavior remain in place.

### Validation and remaining boundaries

- The maintainer accepted the descriptive temporary VSIX before authorizing formal publication. The complete quality gate, 299 tests across 71 suites, main clangd Extension Host regressions and the compiler-macro suite passed; the online dependency audit reported zero vulnerabilities. Main-branch CI now also runs the dedicated macro suite.
- Synthetic assertions cover 2, 5 and 1 exact macro-use locations, three expanded-function calls only through the explicit action, source-macro controls, root anchors and six controlled visibility paths. Controlled controller visibility is not full physical mouse, layout or Remote-environment coverage.
- The CI-REG-049 Callers/refresh fix is accepted; compiler-macro definition anomalies, automatic Code Preview placement and workspace-symbol indexing boundaries remain unresolved. An unrelated numeric-macro target, an alias's expanded-function target and an empty conditional-macro definition are distinct cases. This release does not claim a preview fix, expand Microsoft macro detection, or establish support across other clangd versions.
