# C Insight 0.22.25

## 中文

### 可选固定深浅预览配色

- 代码预览新增 `cInsight.codePreview.colorScheme`：`theme`（默认）、`fixed-dark` 与 `fixed-light`。固定预设同时设置源码背景、普通文字、行号、目标行及目标符号高亮，不随编辑器明暗主题改变。
- `cInsight.codePreview.tokenColors` 默认 `{}`，支持 22 类独立的 `#RRGGBB` 文字颜色覆盖。未指定的类别沿用所选预设；无效值提示并回退，不接受任意 CSS。函数与方法、类型与类等键彼此独立。
- 只影响预览源码区域，不改变主编辑器、标题或工具栏的主题，也不宣称与编辑器的完整 TextMate/语义主题决议逐字符一致。

### 切换颜色不打断浏览

- 配色及 VS Code 主题变化只替换独立样式，不重建源码 HTML、不清空语义和滚动缓存，不增加语义查询，不改变预览目标、锁定或历史。
- 隐藏窗口跳过配色消息，重新显示或页面准备完成时同步最新设置；锁定状态同样适用。
- 保留既有语义分类、超时回退、参数/只读斜体、弃用删除线、源码灰框重置、增量滚动与导航逻辑。

### 文档与验证

- 临时包已获用户验收后合回 `main`，再更新正式版本。中英文用户手册给出全部默认色表、源码区域配色、可直接合并的 `settings.json` 示例和恢复方法。
- 自动回归覆盖纯配色模型、非法输入、实际样式消息分支、双引擎扩展宿主内的受控 Webview、锁定、隐藏/就绪同步、缓存及状态保留；新增文档与默认颜色/配置示例一致性检查。
- 本地完整质量门、295 项测试（71 个套件）、clangd 与 Microsoft C/C++ 两套隔离扩展宿主回归通过；联网依赖审计报告 0 个漏洞。物理滚轮、主题观感和各类 Remote 环境仍按实际环境持续人工回归。
- 新增历史问题驱动测试指南与初始 48 条稳定编号案例，明确自动化边界、人工回归重点和以后反馈问题时的维护要求。本次关联 `CI-REG-020`，不将用户验收泛化为所有主题、Remote 环境或硬件均已测试。

## English

### Optional fixed dark/light preview palettes

- Added `cInsight.codePreview.colorScheme`: `theme` (default), `fixed-dark`, and `fixed-light`. Fixed presets define source background, plain text, gutter and target highlights independently of the editor's light/dark theme.
- `cInsight.codePreview.tokenColors` defaults to `{}` and accepts independent opaque `#RRGGBB` foreground overrides for 22 categories. Unspecified categories retain preset defaults; invalid values warn and fall back rather than becoming arbitrary CSS. Function/method and type/class are separate keys.
- Only the preview source area changes. The editor, preview header and toolbar keep their existing theme behavior; this is not complete editor TextMate/semantic-theme synchronization.

### Change colors without interrupting browsing

- Color-setting and theme changes update a dedicated style element without rebuilding source HTML, clearing token/scroll caches, querying the semantic provider, or changing the preview target, lock or history.
- Hidden views skip style messages and synchronize current settings when shown or ready, including while locked.
- Existing semantic classification, timeout fallback, parameter/readonly italics, deprecated strikethrough, source-row style reset, incremental scrolling and navigation remain unchanged.

### Documentation and validation

- The maintainer accepted the temporary VSIX before merge into `main` and formal versioning. Both user guides include all default colors, source-surface palettes, mergeable `settings.json` examples and reset instructions.
- Automated coverage includes the pure palette model, invalid input, actual style-message branch, controlled Webviews in both analysis-engine Extension Host suites, lock/hidden/ready behavior and retained caches/state. A documentation guard checks preset tables and configuration examples against the runtime model.
- The local complete quality gate, 295 tests across 71 suites, and isolated clangd and Microsoft C/C++ Extension Host regressions passed; the online dependency audit reported zero vulnerabilities. Physical scrolling, appearance and Remote environments remain environment-specific manual regression checks.
- Added a history-driven regression guide and an initial 48-case catalog, separating automated checks, manual gaps and ongoing issue-record maintenance. This feature is tracked under `CI-REG-020`; user acceptance is not a claim of coverage for every theme, Remote environment or hardware combination.

## 安装与校验 / Installation and verification

从 [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.25) 下载 `c-insight-0.22.25.vsix` 和 `SHA256SUMS`，在同一目录运行 `sha256sum -c SHA256SUMS`，然后在 VS Code 中执行 **扩展：从 VSIX 安装...**。首次使用仍默认 `theme`；在设置中选择 `fixed-dark` 或 `fixed-light` 才启用固定配色。默认颜色及示例见[中文用户手册](https://github.com/H9elix/c-insight/blob/v0.22.25/docs/user/user-guide.zh-CN.md#code-preview-default-colors)。

Download `c-insight-0.22.25.vsix` and `SHA256SUMS` from the [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.25), run `sha256sum -c SHA256SUMS`, and use **Extensions: Install from VSIX...**. The default is still `theme`; select `fixed-dark` or `fixed-light` to enable a fixed palette. See the [English defaults and settings examples](https://github.com/H9elix/c-insight/blob/v0.22.25/docs/user/user-guide.en.md#code-preview-colors).
