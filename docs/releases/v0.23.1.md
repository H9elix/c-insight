# C Insight 0.23.1

## 中文

- 组合视图新增独立保存的扩展方向，可通过工具栏箭头或管理菜单切换“双向／向右或下”。默认向右／下，已有布局未指定方向时同样生效。
- 单向扩展只借用目标后方的可压缩空间，连续切换及中断动画时保持目标左侧／顶部边界和前方尺寸；末尾或无余量时不扩展，移出整个组合后统一恢复基础比例。
- 鼠标进入标题、代码预览控件或搜索／结果工具栏时，取消待触发伸缩并冻结当前动画，避免按钮在鼠标下移动。返回内容区的新移动恢复悬停判断，操作区内切换模式不会立即移动按钮；双向模式同样受到保护。

## English

- Added independently saved expansion directions for combined views, selectable through the toolbar arrow or management menu. Forward expansion—right horizontally or down vertically—is the default, including for existing layouts without an explicit direction.
- Forward expansion borrows only trailing slack, preserving the target's leading edge and preceding sizes during consecutive hovers and interrupted animations. Last panes and panes without trailing slack do not expand; leaving the whole combination restores base proportions.
- Entering pane headers, Code Preview controls or search/result toolbars cancels pending resizing and freezes the current animation, keeping click targets stable. Fresh content movement resumes hover handling, and mode changes over controls defer geometry changes until departure. Both-direction mode receives the same protection.
