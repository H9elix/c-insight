# C Insight 0.23.0

## 中文

- 新增最多四个可自定义组合视图，可将代码预览、调用者、引用等 15 种现有功能自由组合，支持水平/垂直排列、拖动分隔条、重命名及保存布局，原独立栏目继续保留。
- 支持平滑悬停扩展，通过压缩相邻窗格突出当前内容；触发等待、动画和移出恢复时间可配置并即时生效，兼容减少动态效果设置，拖动或操作控件时暂停扩展。
- 支持拖动子窗格标题调整顺序，提供插入提示、边缘自动滚动与取消操作，保留窗格比例、折叠状态和浏览位置。
- 原栏目与组合中的相同功能共享结果和固定状态，各显示位置独立保留筛选、展开及滚动；隐藏或折叠的显示位置不触发自动查询。
- 组合总工具栏随排列方向切换左侧竖排或顶部横排，去除外层多余留白，短窄空间中仍可访问全部按钮。
- 组合窗格的滚动条、字体、输入框、菜单和焦点样式跟随 VS Code 主题；切换主题和字体不重置浏览状态，并保留代码预览的固定配色。
- 修复本地化命令标题导致组合创建失败的问题，按钮与窗格名称正确使用翻译文字。

## English

- Added up to four customizable combined views for 15 existing features, including Code Preview, Callers and References, with horizontal/vertical layouts, draggable splitters, renaming and saved layouts. Independent views remain available.
- Added smooth hover expansion that compresses neighboring panes, with live-configurable dwell, animation and restoration delays, reduced-motion support, and interaction pauses.
- Added title dragging to reorder panes with insertion markers, edge scrolling and cancellation while preserving proportions, collapsed state and browsing positions.
- Shared results and pins between independent and combined presentations while retaining local filtering, expansion and scrolling. Hidden or collapsed presentations do not trigger automatic queries.
- Adapted the global toolbar to a left vertical strip for horizontal combinations and a top row for vertical combinations, removed unused outer gutters, and kept all buttons accessible in cramped layouts.
- Matched combined-pane scrollbars, fonts, inputs, menus and focus styling to VS Code themes. Live theme and font changes retain browsing state and fixed Code Preview palettes.
- Fixed combined-view creation with localized command-title objects and used translated names for buttons and panes.
