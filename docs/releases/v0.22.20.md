# C Insight 0.22.20

## 中文

### 正式产品图标

- 新增 256×256 PNG 正式产品图标，以冰蓝色代码框架和青色关系节点表达 C Insight 的源码浏览、调用关系与结构分析能力。
- VS Code Marketplace 和扩展管理界面会使用该 PNG；Activity Bar 继续使用适合主题着色的单色 SVG，避免改变编辑器侧栏中的原有辨识方式。
- Marketplace 清单同步声明与图标背景匹配的深蓝展示横幅和免费扩展属性。

### 打包与验证

- VSIX 资源白名单现在只包含正式产品 PNG 与 Activity Bar SVG，不再把设计候选图、原始素材或 Windows 下载附属信息带入安装包。
- 新增公共仓库契约测试，验证发布者、PNG 签名、256×256 尺寸、文件大小、横幅元数据、定价和候选资源排除规则。
- 完整质量门覆盖编译、静态检查、65 项自动测试、双语本地化、文档一致性、链接、第三方声明和 VSIX 构建；临时安装包已经完成用户验收。

## English

### Official product icon

- Added the official 256×256 PNG product icon, using an ice-blue code frame and cyan relationship nodes to represent C Insight's source browsing, call relationships, and structural analysis.
- The VS Code Marketplace and Extension Manager use the PNG, while the Activity Bar retains its theme-aware monochrome SVG so the existing sidebar identity remains unchanged.
- Marketplace metadata now declares a matching dark-blue gallery banner and explicit free pricing.

### Packaging and verification

- The VSIX asset allowlist now includes only the final product PNG and Activity Bar SVG, excluding design candidates, source artwork, and Windows download metadata from the installation package.
- A public-repository contract verifies publisher identity, the PNG signature, 256×256 dimensions, file size, gallery metadata, pricing, and exclusion of candidate assets.
- The complete quality gate covers compilation, static analysis, 65 automated tests, bilingual localization, documentation consistency, links, third-party notices, and VSIX construction; the temporary package has completed user acceptance.

## 安装与校验 / Installation and verification

从 [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.20) 下载 `c-insight-0.22.20.vsix` 与 `SHA256SUMS`，校验后在 VS Code 中运行 **扩展：从 VSIX 安装...**。完整调用层次建议使用 clangd 20 或更高版本；Microsoft C/C++ 语言服务仍为明确选择后启用的可选引擎。

Download `c-insight-0.22.20.vsix` and `SHA256SUMS` from the [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.20), verify the checksum, and run **Extensions: Install from VSIX...** in VS Code. clangd 20 or newer is recommended for complete Call Hierarchy support; the Microsoft C/C++ language service remains an explicitly selected optional engine.
