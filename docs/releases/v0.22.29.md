# C Insight 0.22.29

## 中文

- 文档符号的搜索交互与工程文件对齐：未锁定时，双击、Enter 或右键“打开位置”成功跳转后自动清空过滤词，重复打开同一符号也适用；单击预览保留过滤词。
- 在搜索框、结果列表、右键菜单或排序菜单中操作时，暂停自动清空和滚动；独立锁定后保留过滤词及滚动位置，当前文档与中心高亮继续更新。
- 焦点离开后，自动跟随仅在过滤词隐藏编辑器中心符号时清空；仍匹配时保留搜索，并尽量将目标居中。修复层级筛选结果仍命中时被错误清空的问题。
- 关闭中心跟随时，成功打开结果仍可清空过滤词，但不滚动或展开父级；隐藏后重新显示保留搜索状态，打开失败或迟到结果不会覆盖新输入。

## English

- Aligned Document Symbols search interaction with Project Files: successful unlocked double-click, Enter and context-menu Open Location actions clear the filter, including repeated opens of the same symbol. Single-click previews preserve it.
- Search-box, result-list, context-menu and sort-picker interaction pause automatic clearing and scrolling. Independent locking retains the query and scroll position while document data and center highlighting continue to update.
- Outside the view, automatic following clears only a query hiding the editor-center symbol; matching queries remain and the target is centered where possible. Fixed matching hierarchical search results being incorrectly cleared.
- With center following disabled, successful opens still clear the filter without scrolling or expanding ancestors. Hidden views retain search state, and failed or delayed opens cannot overwrite newer input.
