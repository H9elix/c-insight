# C Insight 0.22.19

## 中文

### 保留宏身份的调用者

- 当对象式或函数式宏展开为函数时，调用者不再静默切换到展开后函数的所有调用位置。根节点保留用户实际选择的宏名称，并通过该宏自身的引用列出准确使用位置。
- 光标位于宏调用处或 `#define` 左侧的宏定义名上时，都能查询相同的直接使用位置。宏定义行、其他宏别名以及直接调用展开后函数的位置不会混入默认结果。
- 每个宏使用位置仍映射到其外层可调用符号；同一函数中的重复使用分别显示，规范调用点可以继续向上展开调用者。

### 显式查询展开后的函数

- 调用者标题栏和宏根节点右键菜单提供**查询宏展开后函数的调用者（Show Expanded Function Callers）**，只替换当前调用者树，不改变被调用者、关系图或宏引用结果。
- 从实际宏使用处执行时会复用分析提供程序原始调用层次根；从宏定义处执行时，只在用户点击后按需检查最多 16 个实际使用位置，并缓存首个可用目标。
- 无法解析可调用目标时保留已有宏结果。普通函数和默认宏查询不会承担这项按需解析开销。

### 项目首页与验证

- 重构中英文项目首页，使项目目标、核心交互、快速开始、分析引擎边界和文档入口更易发现，并加入经过隐私遮罩的概览、导航、调用层次和关系图演示素材。
- 新增宏定义名范围、未解析目标缓存键和宏定义调用者回归；扩展宿主覆盖宏调用处、宏定义处、准确调用位置、刷新恢复以及按需切换展开目标。
- 完整质量门覆盖编译、静态检查、自动测试、双语本地化、文档一致性、链接、第三方声明和 VSIX 构建；临时安装包已完成用户验收。

## English

### Macro-identity Callers

- When an object-like or function-like macro expands to a function, Callers no longer silently switches to every call of the expanded function. The root keeps the macro name actually selected by the user and derives exact use locations from References to that macro.
- The same direct uses are available with the cursor either on a macro invocation or on the left-hand macro name in its `#define`. The definition line, other aliases, and direct calls to the expanded function are excluded from the default result.
- Every macro use is still mapped to its enclosing callable. Repeated uses in one function remain separate, and the canonical occurrence can continue upward through that function's callers.

### Explicit expanded-function queries

- **Show Expanded Function Callers** is available in the Callers title bar and macro-root context menu. It replaces only the current Callers tree and does not change Callees, Relationship Graph, or macro-reference results.
- From an actual macro use, the action reuses the Provider's original Call Hierarchy root. From a macro definition, it checks at most 16 actual uses only after the user invokes the action and caches the first callable target it can prepare.
- A failed target resolution leaves the macro-use result intact. Ordinary functions and default macro queries do not pay this on-demand resolution cost.

### Project landing pages and verification

- The English and Simplified Chinese landing pages now lead with the project purpose, visible workflow, quick start, engine boundary, and documentation entry points, supported by privacy-masked overview, navigation, call-hierarchy, and relationship-graph media.
- New regression coverage exercises macro-definition name ranges, unresolved-target cache identity, macro invocation and definition queries, exact use locations, refresh restoration, and on-demand expanded-target switching in the Extension Host.
- The complete quality gate covers compilation, static analysis, automated tests, bilingual localization, documentation consistency, links, third-party notices, and VSIX construction; the temporary package has completed user acceptance.

## 安装与校验 / Installation and verification
