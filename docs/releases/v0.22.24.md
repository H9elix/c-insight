# C Insight 0.22.24

## 中文

### 编辑器后退/前进不再多停留一次

- 修复从代码预览、调用者、被调用者及其他源码结果跳转后，第一次后退先回到目标文件上次关闭位置的问题。文件打开时直接指定目标光标，不再先恢复旧位置、再执行一次光标跳转。
- 共享结果树的双击与 Enter、打开位置、转到定义、代码预览的双击及打开编辑器按钮、关系图节点打开均采用同一定位入口；已打开文件和同文件跳转也适用。
- 鼠标侧键绑定 VS Code 原生后退/前进时，可直接往返跳转前位置与目标位置，不再为本次文件打开额外生成恢复位置站点。

### 保持原有交互与历史

- 不清空原生导航历史，不接管鼠标按键，也不追溯删除旧版本已生成的冗余记录。请使用新的一次跳转验证修复；代码预览自己的浏览历史仍独立管理。
- 保留光标折叠、编辑器焦点、居中显示及标签页策略；关系图仍使用非预览标签和条件居中。
- 不改变双击后延迟跟随、固定/锁定或树展开状态，不新增配置项，也不增加语义查询。

### 验证与文档

- 临时 VSIX 已通过用户验收，之后才进行正式版本更新。
- 完整质量门、284 项测试（69 个套件）及 clangd、Microsoft C/C++ 两套真实 VS Code Extension Host 回归通过。导航历史回归覆盖关闭文件的旧光标、已打开文件、同文件跳转、多轮原生后退/前进、代码预览消息、树激活和关系图非预览标签。
- 中英文 README、用户手册、交叉编译指南、架构、开发者手册、文档索引和路线图同步为当前版本。新增导航历史修复验证记录，历史发布说明和带日期的测量保持原意。

## English

### Remove the extra editor Back/Forward stop

- Fixed the first Back action after source navigation returning to the target file's last-closed position instead of the original location. The editor-open request now includes the target caret, rather than restoring an old caret and moving it separately.
- Shared result-tree double-click and Enter, Open Location, Go to Definition, Code Preview double-click and Open in Editor, and Relationship Graph node opening use one location-opening helper. Already-open files and same-file jumps use the same path.
- Mouse side buttons bound to native VS Code Back/Forward now travel directly between the origin and destination without an extra restored-position entry introduced by the file opening.

### Preserve interaction and history

- Native history is not cleared, mouse bindings are not intercepted, and redundant entries created by older versions are not removed retroactively. Verify with a fresh navigation; Code Preview's own browsing history remains separate.
- Collapsed carets, editor focus, centering, and tab policies are preserved. Relationship Graph keeps non-preview tabs and conditional centering.
- Double-click cursor-follow suppression, pin/lock controls, and branch expansion are unchanged. No new setting or semantic query is introduced.

### Validation and documentation

- The user accepted the temporary VSIX before formal versioning.
- The complete quality gate, 284 tests across 69 suites, and real VS Code Extension Host regressions for both clangd and Microsoft C/C++ passed. Navigation cases include remembered positions in closed files, already-open targets, same-file jumps, repeated native Back/Forward, Code Preview messages, tree activation, and non-preview graph tabs.
- Bilingual READMEs, user and cross-compilation guides, architecture, developer documentation, the documentation index, and roadmap match the current version. A navigation-history validation report records the reproduction and checks; historical release notes and dated measurements retain their original meaning.

## 安装与校验 / Installation and verification

从 [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.24) 下载 `c-insight-0.22.24.vsix` 与 `SHA256SUMS`，在同一目录执行 `sha256sum -c SHA256SUMS`，然后在 VS Code 中运行 **扩展：从 VSIX 安装...**。本版不改变分析引擎要求；完整调用层次建议使用 clangd 20 或更高版本，Microsoft C/C++ 仍为可选引擎。

Download `c-insight-0.22.24.vsix` and `SHA256SUMS` from the [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.24), run `sha256sum -c SHA256SUMS` in the same directory, and use **Extensions: Install from VSIX...** in VS Code. Analysis-engine requirements are unchanged: clangd 20 or newer is recommended for complete Call Hierarchy support, and Microsoft C/C++ remains optional.
