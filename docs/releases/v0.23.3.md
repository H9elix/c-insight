# C Insight 0.23.3

## 中文

- 为组合视图的每个子栏目新增独立的悬停展开目标占比。可在子栏目菜单中设置 `1–100%` 或恢复默认，配置随栏目排序保留；未设置时沿用原有加权展开效果，并继续遵守扩展方向和相邻栏目的最小尺寸。
- 修复文档符号、工程文件在展开后上下滚动，再缩回时高亮项未恢复可见的问题。连续多轮操作均会在缩回后检查目标；不可见时居中，仍可见时保持原滚动位置，展开浏览期间不会拉回。
- 缩回后的居中定位改为可打断的平滑滚动。滚轮、搜索、锁定或显式导航会停止旧动画，启用系统或 VS Code 的减少动态效果时直接定位；筛选、树展开及其他显示实例保持不变。

## English

- Added an independent hover expansion target percentage for each combined-view pane. Set `1–100%` or restore the default from its pane menu; targets stay with panes when reordered. Unset panes retain weighted expansion, and direction and neighboring minimum-size limits still apply.
- Fixed Document Symbols and Project Files losing their followed highlight after wheel browsing in an expanded pane and then contracting it. Repeated cycles now restore out-of-view targets while leaving visible rows in place and keeping expanded browsing uninterrupted.
- Centering after contraction now uses interruptible smooth scrolling. Wheel input, search, locking or explicit navigation stops the previous animation; system or VS Code reduced-motion preferences use immediate positioning. Filters, tree expansion and other presentation instances stay unchanged.
