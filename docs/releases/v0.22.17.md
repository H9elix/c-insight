# C Insight 0.22.17

## 中文

### 编辑期间的查询抑制

- 文本编辑不再自动重复上下文、代码预览、引用、调用者和被调用者等语义查询，避免输入代码时持续占用 clangd 或 Microsoft C/C++ 语言服务。
- 输入引发的多个光标/选区事件会与原始编辑关联；即使字符输入间隔较长，或者 VS Code 报告的光标位置与文本变更终点略有偏移，也不会误判成主动导航。
- 用户随后使用鼠标或方向键移动到其他符号，或者执行刷新、查找引用和调用层次等显式命令时，查询会立即恢复。

### 后台资源优化

- 相同标识符内部、空白处以及当前文档版本中已经确认无符号的位置不会重复触发等价的光标查询。
- 调用层次和类型层次缓存在编辑后标记为过期，但只在下一次真实层次查询时清理；已加载的树可以暂时保留为过期结果。
- 文档符号、代码预览、包含关系和工程诊断的编辑驱动任务会合并执行；未变化的包含指令会被跳过，关系图和结果过期通知保持幂等。

### 验证

- 新增单元测试，覆盖连续选区事件、轻微位置偏移、慢速输入、主动移动恢复和显式命令旁路。
- 扩展宿主测试以约 1.2 秒间隔输入多个字符，确认定义、声明、悬停、引用、符号信息和调用层次请求均不增加，并验证随后主动移动会恢复查询。

## English

### Query suppression while editing

- Text edits no longer automatically repeat semantic queries for Context, Code Preview, References, Callers, or Callees, avoiding continuous clangd or Microsoft C/C++ language-service work while code is being entered.
- Multiple caret or selection events caused by one edit are associated with that edit. Slowly spaced characters and small differences between the reported caret position and the text-change endpoint are no longer mistaken for deliberate navigation.
- Queries resume immediately after mouse or arrow-key navigation to another symbol, or when an explicit Refresh, Find References, or Call Hierarchy command is run.

### Background resource improvements

- Movement within the same identifier, whitespace, and positions already confirmed symbol-free for the current document version no longer repeat equivalent cursor queries.
- Call and Type Hierarchy caches are marked stale after edits but cleared only by the next actual hierarchy request; loaded trees can remain visible as stale results in the meantime.
- Edit-driven Document Symbols, Code Preview, Include Hierarchy, and Project Diagnostics work is coalesced. Unchanged include directives are skipped, while Relationship Graph and stale-result publication remain idempotent.

### Verification

- Unit coverage now includes repeated selection events, small position displacement, slowly spaced input, deliberate-navigation recovery, and explicit-command bypass.
- The Extension Host test enters multiple characters about 1.2 seconds apart, verifies that definition, declaration, hover, references, symbol-information, and call-hierarchy request counts remain unchanged, and confirms that deliberate movement resumes querying.

## 安装与校验 / Installation and verification

从 [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.17) 下载 `c-insight-0.22.17.vsix` 与 `SHA256SUMS`，校验后在 VS Code 中运行 **Extensions: Install from VSIX...**。完整调用层次建议使用 clangd 20 或更高版本；Microsoft C/C++ 语言服务仍为明确选择后启用的可选引擎。

Download `c-insight-0.22.17.vsix` and `SHA256SUMS` from the [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.17), verify the checksum, and run **Extensions: Install from VSIX...** in VS Code. clangd 20 or newer is recommended for complete Call Hierarchy support; the Microsoft C/C++ language service remains an explicitly selected optional engine.
