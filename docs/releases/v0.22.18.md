# C Insight 0.22.18

## 中文

### 代码预览选择稳定性

- 在调用者、被调用者、引用、导航历史、关系图或代码预览中显式选择源码位置后，代码预览会保留该位置，不再被旧光标上下文的延迟结果跳回符号定义。
- 代码预览所有权现在与上下文代次绑定。延迟返回的上下文详情以及 2 秒、10 秒的首选定义重试仍可完成各自任务，但不能覆盖更新的显式选择。
- 用户主动使用鼠标或键盘移动编辑器光标，或者执行显式刷新和查询命令时，当前编辑器上下文会重新取得代码预览更新权；仅由视图重新可见触发的刷新不会夺回显式选择。
- 代码预览锁定仍具有最高优先级，其现有固定行为不受本次修改影响。

### 诊断与验证

- 工程诊断运行时计数新增 `navigation.preview.staleContextSuppressed`，用于观察被阻止的过期上下文预览写入。
- 新增预览所有权单元测试，并在扩展宿主中覆盖默认 600 毫秒上下文详情延迟、2 秒首选定义重试、显式调用点选择保持，以及随后主动移动光标恢复上下文跟随。
- 发布质量门继续覆盖编译、静态检查、249 个单元测试、文档一致性和 VSIX 打包；用户已经完成临时安装包冒烟验收。

## English

### Stable explicit Code Preview selections

- After a source location is explicitly selected from Callers, Callees, References, Navigation History, Relationship Graph, or Code Preview, the preview now stays at that location instead of jumping back to the old cursor symbol's definition.
- Code Preview ownership is now bound to the context generation. Delayed context details and the 2-second or 10-second preferred-definition retries may still finish their own work, but cannot overwrite a newer explicit selection.
- Deliberate mouse or keyboard movement in the editor, or an explicit refresh or query command, returns preview ownership to the current editor context. A visibility-only refresh does not take ownership away from an explicit selection.
- Code Preview locking remains the stronger rule, so existing pinned behavior is unchanged.

### Diagnostics and verification

- Project Diagnostics runtime counters now include `navigation.preview.staleContextSuppressed` for observing suppressed stale-context preview writes.
- Preview-ownership unit coverage and Extension Host coverage exercise the default 600 ms context-detail delay, the 2-second preferred-definition retry, explicit call-site stability, and context following after deliberate cursor movement.
- The release quality gate continues to cover compilation, static checks, 249 unit tests, documentation consistency, and VSIX packaging; the temporary package has also completed user smoke acceptance.

## 安装与校验 / Installation and verification

从 [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.18) 下载 `c-insight-0.22.18.vsix` 与 `SHA256SUMS`，校验后在 VS Code 中运行 **Extensions: Install from VSIX...**。完整调用层次建议使用 clangd 20 或更高版本；Microsoft C/C++ 语言服务仍为明确选择后启用的可选引擎。

Download `c-insight-0.22.18.vsix` and `SHA256SUMS` from the [GitHub Release](https://github.com/H9elix/c-insight/releases/tag/v0.22.18), verify the checksum, and run **Extensions: Install from VSIX...** in VS Code. clangd 20 or newer is recommended for complete Call Hierarchy support; the Microsoft C/C++ language service remains an explicitly selected optional engine.
