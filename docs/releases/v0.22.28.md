# C Insight 0.22.28

## 中文

- 文档符号新增常驻搜索框，输入时实时按名称进行大小写不敏感的子串筛选；支持一键清空、Escape 清空及 Ctrl+F/Cmd+F 聚焦。
- 搜索包含折叠分支中已加载的类和结构体成员，保留父级上下文；搜索中的展开和折叠不改变普通树的展开记录。编辑器中心更新不清空搜索，也不拉动筛选结果的滚动位置。
- 新增独立锁定/解锁按钮，暂停自动滚动和父级展开，同时继续更新当前文档内容及编辑器中心高亮。解锁后恢复定位，锁定/解锁、排序和刷新按钮保持固定槽位。
- 新增按源码位置、名称或符号类型排序，仅重排同层节点，保留层级、筛选、高亮和展开状态。排序使用已加载符号，无需再次查询分析引擎。

## English

- Added a persistent Document Symbols search box with live, case-insensitive name-substring filtering, one-click clearing, Escape to clear, and Ctrl+F/Cmd+F to focus.
- Search includes loaded class and struct members inside collapsed branches and retains ancestor context. Search expansion stays separate from ordinary tree expansion, while editor-center updates preserve the query and filtered scroll position.
- Added independent Lock/Unlock controls to pause automatic scrolling and ancestor expansion while keeping the active document and editor-center highlight live. Unlock resumes reveal, and Lock/Unlock, Sort, and Refresh retain stable title-bar slots.
- Added source-position, name, and symbol-type sorting among siblings, preserving hierarchy, filters, highlights, and expansion. Sorting uses loaded symbols without another analysis-engine request.
