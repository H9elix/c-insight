# C Insight 0.24.1

## 中文

### 0.24.1 更新

- 精简“搜索与替换”布局：常用匹配选项采用紧凑按钮，文件筛选与搜索详情默认折叠，隐藏的有效条件仍显示摘要，错误和部分结果提示保持可见。
- 搜索范围、导航和文件筛选移到搜索框上方，展开的替换输入紧接搜索框；结果复选框随替换区域显示，收起保留勾选，各显示实例独立记忆本次会话的筛选／详情展开状态。
- 代码预览将类型、符号、文件位置和工具栏合为单行，完整路径与加载范围通过悬停查看，移除独立底部状态行。加载失败保持可见，元数据及状态更新不挤动正在阅读的代码，窄栏支持工具栏局部滚动和键盘访问。
- 提供 Windows、Linux、macOS 的 7 个平台专用安装包及 Universal 通用包，并附统一 SHA-256 校验清单；在 Remote 环境按扩展宿主平台选择。

### 0.24 版本新增功能

- 新增“搜索与替换”视图，不依赖 clangd 或微软 C/C++ 分析引擎，可独立使用或加入组合视图。支持当前文件、打开文件、指定文件夹及整个工作区的文本搜索，提供大小写、整词、正则、跨行及包含／排除选项；按 Enter 或点击搜索显式启动。
- 安装包自带原生搜索后端，直接读取匹配结果，提升工作区搜索速度，并优先使用未保存内容；遵循忽略规则、编码及符号链接设置。匹配数量共用 VS Code 的 `search.maxResults`，默认 20000，设为 `null` 可不限数量。
- 普通栏目默认显示前 200 个匹配，可通过 `cInsight.textSearch.inlineResultLimit` 调整，完整结果继续用于浏览和替换。上方“打开结果窗口”可保留本轮查询的只读快照；运行中持续接收本轮结果，完成或取消后固定，不被新查询覆盖。不同查询窗口可并存，单击代码预览，双击或 Enter 打开编辑器。
- 支持对当前、勾选、单文件或全部匹配生成替换差异预览，提供正则捕获组替换和保留大小写。明确确认后以未保存的编辑应用，可使用 VS Code 撤销；源码变化会标记结果过期，应用前核对内容和版本。

### 0.23 版本新增功能

- 新增组合视图，可将代码预览、调用者、引用等功能放到同一个视图中，最多保存四个命名组合，支持水平或垂直排列，原有独立视图仍可使用。
- 支持拖动子栏目标题排序、拖动分隔条调整尺寸及折叠窗格，整套内部布局可跨工程复用；同一功能共享查询结果和固定状态，树窗格保留各自的筛选、展开和滚动位置。
- 鼠标悬停时平滑扩大当前阅读区域，移出组合后恢复比例；支持单向或双向扩展及可配置的触发、动画和恢复时间，标题与按钮操作区保持位置稳定。组合内的滚动条、界面和代码字体随 VS Code 主题及字体设置更新。

## English

### 0.24.1 updates

- Simplified Search & Replace with compact match toggles, file filters and search details collapsed by default, visible active-filter summaries, and always-visible errors and partial-result warnings.
- Moved scope, navigation and file filters above the query so expanded replacement inputs remain adjacent. Replacement-only checkboxes retain selections when hidden; each presentation independently remembers filter/details expansion for the current session.
- Combined Code Preview type, symbol, file location and tools into one header row, with full paths and loaded-range details in hover tips instead of a separate footer. Loading failures stay visible without shifting the source, metadata updates retain reading position, and narrow toolbars support local scrolling and keyboard access.
- Added seven Windows, Linux and macOS platform-specific VSIX packages alongside Universal and a shared SHA-256 manifest. Choose packages for the extension host in Remote sessions.

### New in 0.24

- Added an engine-independent Search & Replace view, available on its own or inside combined views. Search the current file, open files, a selected folder or the entire workspace, with case, whole-word, regex, multiline and include/exclude options. Press Enter or Search to run explicitly.
- The bundled native backend streams matches directly for faster workspace searches, with unsaved-buffer priority and support for ignore, encoding and symlink settings. Match limits follow VS Code's `search.maxResults`: 20000 by default, or `null` for no match-count limit.
- Small views display the first 200 matches by default, configurable with `cInsight.textSearch.inlineResultLimit`, while retaining complete results for browsing and replacement. Open results window above the list creates a read-only snapshot of that query, continuing to collect its running results and fixing them on completion or cancellation. New searches never overwrite old windows; different queries can coexist. Single-click previews source, while double-click or Enter opens the editor.
- Preview replacement diffs for the current match, checked matches, one file or all matches, with regex captures and preserve-case support. Explicitly confirmed edits remain unsaved and support VS Code undo. Source changes mark results stale, and replacement rechecks content and document versions before applying edits.

### New in 0.23

- Added combined views that place Code Preview, Callers, References and other features together. Save up to four named horizontal or vertical combinations while retaining the original independent views.
- Reorder panes by dragging their titles, resize them with splitters, collapse panes and reuse the internal layout across projects. Feature results and pins are shared, while tree panes retain their own filtering, expansion and scrolling.
- Smoothly enlarge the reading pane on hover and restore proportions when leaving the combination. Choose forward or both-direction expansion and configure dwell, animation and restoration timing; protected titles and controls keep click targets stable. Embedded scrollbars, UI typography and code fonts follow VS Code theme and font settings.
