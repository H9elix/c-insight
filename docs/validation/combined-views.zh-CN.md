## CI-REG-056 多轮滚动后缩回与平滑定位（2026-11-24）

维护者用录屏确认首次临时包仍有问题：展开后上下滚远再缩回，后续循环不再定位，已定位时也有突跳。原因是滚轮清空了跟随锚点，而且尺寸修正只识别此前仍可见的目标。现在滚轮停止待执行修正和动画但保留目标身份，收缩后检查目标是否越界；展开期间不拉回，缩回时平滑居中，仍可见不滚动。锁定、跟随、焦点、筛选及缓存边界不变，减少动态效果时直接定位。

`npm run check`、71 项浏览器／控制器／消息边界定向检查、VS Code `1.130.0` 和 `1.95.0` 的独立视口专项，以及 `1.130.0` 原生工程文件专项通过。视口专项分别对文档符号和工程文件执行三轮展开／上下滚远／缩回，检查每轮一次定位、真实动画中间位置、展开浏览不被打断、仍可见不动及零新增语义请求。专项不依赖引擎，可独立运行：

## 人工重点

1. 用命令创建组合，添加代码预览、调用者、引用；将其移动到下方，确认原栏目保持原布局。
2. 鼠标在三个窗格之间移动，分别测试中央、边缘、快速掠过、停留和移出；扩展压缩相邻窗格，边界动画连续，不因边界移动来回抖动。树选择、筛选词、预览行位置和横向滚动不变。
3. 拖动分隔条、选中文本、按住鼠标、打开功能菜单时不自动调整；释放或结束后可恢复悬停。减少动态效果模式不播放过渡。
4. 在各栏“…”菜单选择双向、向右／下、向左／上或默认，测试横纵排列及连续混合悬停。向右／下保持起点，向左／上保持末端，只借指定侧余量；双向可调整两侧，无空间不反向借用。新布局和恢复默认的栏目在当前未折叠末尾时双向，排序／折叠后重新判断；显式选择不随位置变化。旧布局读取保留原表现，不在打开时改写设置；首次用户编辑后保存逐栏格式。总工具栏四个按钮，没有统一方向入口。重载核对方向、比例和其他组合隔离；单栏、全部折叠和窄区域仍可操作。
5. 在两个组合和原栏目同时显示调用者/引用，分别展开、筛选和滚动；锁定在各显示位置同步，调用者/被调用者共用固定，引用不串扰。单击预览、双击/Enter 打开只执行对应动作，编辑器后退不增加中间站点。
6. 文档符号和工程文件的搜索、“×”、Escape、成功打开清空、焦点暂停、独立锁定及居中跟随分别检查；排序菜单期间不清空正在操作的输入。连续至少三轮悬停放大、上下滚远再移出缩回，展开浏览不被打断，每次缩回后若高亮不可见则平滑居中，仍可见不滚动。锁定、关闭跟随或焦点在视图内时不定位；滚轮、搜索、锁定及显式导航打断旧动画，减少动态效果时直接定位。不清空筛选、不展开祖先，也不新增语义查询或文件扫描（CI-REG-056）。
7. 添加/移除全部可选功能，连续重命名、重排、等分、删除及重建；隐藏/折叠后观察运行时计数，悬停和比例变化不增加语义请求，同功能多实例只保留一个查询控制器。
8. 重载窗口及换另一个工程，布局定义保留；用户设置只包含布局，不包含源码路径。外部停靠位置按 VS Code 的保存结果恢复。另在 WSL/SSH、本地、中文/英文、明暗及高对比度主题下验收。
9. 在子窗格聚焦时，检查 Ctrl+Shift+P/F1、终端切换等全局快捷键，以及输入框的复制、粘贴、撤销和全选。树自己的 Ctrl+F、方向键和 Enter 不得重复交给全局处理。
10. 与独立栏目并排比较长行、长列表的横纵滚动条，检查默认、悬停、按住及两轴交汇角落。切换深浅/高对比度主题、修改编辑器字体和字号，检查界面/代码字体、搜索框、菜单、选中态和键盘焦点；源码无灰框，固定预览深浅配色保留。切换前输入筛选、展开树并滚动，切换后位置与状态不应清空或闪回。
