# 组合视图验证

组合视图（Combined View）将现有功能显示层挂载到同一原生 Webview 内。此项是可选布局功能；共享查询、导航、固定、筛选和预览的既有规则沿用 CI-REG-022–028、037、042–043。

## 自动覆盖

- `test/unit/combinedModel.test.ts`：四槽默认值、15 功能目录、配置清理、比例预算、最小尺寸、菜单条件、HTML 转义与 CSP nonce。
- `test/unit/combinedBridge.test.ts`：子窗格 API 状态隔离、消息来源、旧 Chromium 主题变量及启动/运行时槽位可见性。
- `test/unit/combinedManifestRuntime.test.ts`：直接执行管理器，覆盖字符串和本地化对象命令标题、原文及非法字段回退、视图名称和非字符串图标；关联 CI-REG-050。宿主还通过真实创建命令及多选框确认检查入口，而非仅通过设置加入窗格。
- `test/e2e/suite/combinedViews.ts`：真实子文档消息桥、全部功能角色的脚本初始化、重复显示不增加查询、共享调用查询、代码预览、工程文件扫描、树展开隔离、筛选保留、受控布局中的横纵悬停和分隔条、主题变量、请求计数、折叠释放以及隐藏期间移除重加的文档代次。测试使用独立 VS Code 用户目录，不操作日常窗口。
- `test/e2e/suite/previewPresentationOwnership.ts`：受控迟到定义的显式覆盖、发起/非发起实例的销毁取消边界，以及隐藏期间修改文档后重新显示的版本恢复。
- `test:e2e`、`test:e2e:project-files` 和 `test:e2e:microsoft`：原有栏目及共用导航、搜索和锁定路径。

C_INSIGHT_COMBINED_ENGINE=microsoft C_INSIGHT_VSCODE_EXECUTABLE_PATH=/path/to/code xvfb-run -a node dist/test/e2e/runCombinedViewTest.js

## 人工重点

1. 用命令创建组合，添加代码预览、调用者、引用；将其移动到下方，确认原栏目保持原布局。
2. 鼠标在三个窗格之间移动，分别测试中央、边缘、快速掠过、停留和移出；扩展压缩相邻窗格，边界动画连续，不因边界移动来回抖动。树选择、筛选词、预览行位置和横向滚动不变。
3. 拖动分隔条、选中文本、按住鼠标、打开功能菜单时不自动调整；释放或结束后可恢复悬停。减少动态效果模式不播放过渡。
4. 切换垂直排列并放到侧栏，确认按高度扩展。窄布局、只有一个展开窗格、全部折叠及重新展开应保持可操作，空间不足时内部滚动。
5. 在两个组合和原栏目同时显示调用者/引用，分别展开、筛选和滚动；锁定在各显示位置同步，调用者/被调用者共用固定，引用不串扰。单击预览、双击/Enter 打开只执行对应动作，编辑器后退不增加中间站点。
6. 文档符号和工程文件的搜索、“×”、Escape、成功打开清空、焦点暂停、独立锁定及居中跟随分别检查；排序菜单期间不清空正在操作的输入。
7. 添加/移除全部可选功能，连续重命名、重排、等分、删除及重建；隐藏/折叠后观察运行时计数，悬停和比例变化不增加语义请求，同功能多实例只保留一个查询控制器。
8. 重载窗口及换另一个工程，布局定义保留；用户设置只包含布局，不包含源码路径。外部停靠位置按 VS Code 的保存结果恢复。另在 WSL/SSH、本地、中文/英文、明暗及高对比度主题下验收。
9. 在子窗格聚焦时，检查 Ctrl+Shift+P/F1、终端切换等全局快捷键，以及输入框的复制、粘贴、撤销和全选。树自己的 Ctrl+F、方向键和 Enter 不得重复交给全局处理。

自动宿主中的受控布局和鼠标事件不能代替真实硬件的动画手感、拖放或 Remote 验收。交付时记录实际执行版本与结果，不将预期写作通过证据。

## 本地验证记录（2026-11-21）

源码基于 `0.22.29`，分支为 `feature/combined-browsing`。完整质量门、合成性能基准、VS Code `1.130.0`/`1.95.0` 的 clangd 主宿主、`1.130.0` 工程文件专项，以及 `1.130.0` clangd/Microsoft 和 `1.95.0` clangd 组合宿主检查通过。Microsoft 测试使用 cpptools `1.35.6`，先等待初始定义分析就绪再执行调用查询。最低版本另验证预先保存组合、不打开 C/C++ 文件时的视图激活。

实际浏览器检查包含主题变量与 Codicons CSS、局部展开、过滤词保留、尺寸预算、悬停前后文档代次和请求计数；布局变化不增加语义请求。初测发现子文档本地字体资源代理、旧 Chromium 主题枚举和运行时槽位可见性差异，已分别通过窗口级字体 Blob、根元素声明变量与运行时上下文键处理，并加入回归覆盖。

一次最低版本主宿主初跑触发 CI-REG-014 的调用点所有权时序断言；保留原生聚焦命令的等待路径后复验通过，未独立确认初跑的具体时序触发条件。多显示实例共用预览定义查询的取消代次，新的显式位置会撤销旧查询。

临时包为 `c-insight-0.22.29-combined-browsing-preview.vsix`。尚待维护者验收；真实鼠标手感、实际布局拖放、辅助技术及 WSL/SSH 检查按上节执行。本次不提升正式版本、不推送或发布。

## CI-REG-050 本地化标题兼容（2026-11-21）

维护者报告创建组合时报 `command.title.replace is not function`。运行时清单的标题可以是 `{ value, original }`，组合管理器现统一提取字符串并提供回退；窗格名称和图标字段也经过类型检查。新增运行时管理器测试修复前 10 个案例有 9 个失败，修复后全部通过，完整质量门及 `1.130.0`/`1.95.0` 的真实命令创建和组合回归通过。

修复临时包为 `c-insight-0.22.29-combined-localized-titles-preview.vsix`。本地宿主虽然尝试指定中文，但实际仍使用英文；中文标题对象已通过确定性案例验证，真实中文安装环境需人工检查创建、多选添加、工具栏及窗格标题。待维护者验收，不推送或发布。
