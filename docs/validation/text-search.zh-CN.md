# 搜索与替换验证

搜索与替换（Search & Replace）使用独立文本匹配线程，不调用 clangd 或 Microsoft 查询。相关共性回归为 CI-REG-022（导航）、035（编辑不自动查）、037（有效可见性）和 038（取消／资源预算）。

## 自动检查

```bash
npm run check
C_INSIGHT_VSCODE_EXECUTABLE_PATH=/path/to/test/code xvfb-run -a node dist/test/e2e/runTextSearchTest.js
```

启动器在临时多根目录生成合成文本、嵌套忽略规则和二进制样本，使用隔离用户数据和扩展目录，不操作当前工作窗口。最低支持版 VS Code 1.95 和当前测试版分别执行同一入口。

- `textSearchModel.test.ts`：字面量、大小写、Unicode 整词、CRLF／UTF-16 位置、多行正则、零宽匹配、结果上限、捕获组／保留大小写、BOM／GBK／二进制拒绝、忽略规则、条件排除、正则超时与线程重建、立即取消。
- `textSearchWebview.test.ts`：有效脚本、nonce CSP、只用 DOM 文本写入结果、视图内快捷键、无输入防抖扫描、修订号和已知 ID 导航约束。
- `textSearchSafety.test.ts`：未信任、只读、超过 200 文件、内容冲突及文档版本变化的拒绝路径。
- `suite/textSearch.ts`：真实多根扫描、未保存文档、默认／关闭忽略、上限、取消、只读差异、版本／内容冲突、单文件和跨文件原生撤销、视图预览／编辑器打开、输入及编辑零扫描、旧差异失效、实际替换后的剩余匹配与零引擎请求。
- 同一宿主还覆盖 1000 个文件／10000 个结果的上限、事件循环响应和零批量打开；全部隐藏时取消、重显不重搜；两个真实组合 Webview 的输入／搜索／复选框共享和分组展开独立；原先未命中文件编辑后的查询失效。

## 人工重点

1. 打开视图，输入查询并停留，确认没有自动扫描；分别用 Enter 和按钮启动。切换当前文件、打开文件、文件夹和多根范围，核对包含／排除过滤及状态计数。
2. 用中文、正则、空匹配和跨行表达式查找；检查片段和行列号。单击预览，双击／Enter 打开编辑器，原生后退一次返回原位置，查询保留；编辑器 Ctrl+F/H 仍为原生查找／替换。
3. 在明暗及高对比度主题下检查输入框、选中项、匹配标记、滚动条、键盘焦点和代码字体。中文与英文界面分别检查。
4. 独立视图和两个组合同时显示本功能：查询、结果和勾选应同步，滚动／折叠保持各自状态。全部隐藏或折叠后扫描停止，重新显示只展示已有部分结果，不重搜。
5. 分别预览当前、勾选、文件和全部替换。更改查询、替换词、勾选或源文件后，旧预览不能应用；在确认对话框取消不修改源文件。应用后保持未保存，撤销还原；新增的同词不应进入本批剩余匹配。
6. 在只读文件系统、文件权限限制、未受信任工作区和 WSL／SSH 环境检查替换拒绝与本地执行位置；大工程检查取消响应、跳过／截断提示及资源上限。

临时包交付后由维护者完成鼠标、主题和实际 Remote 环境验收，再授权合并或发布。
