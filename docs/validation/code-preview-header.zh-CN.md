# 代码预览单行头部验证

代码预览（Code Preview）将预览类型、符号、文件名及目标行号和原有工具栏合为一行，代码区独立滚动。完整路径在头部提示中，已加载行范围及边界在信息图标提示中；加载失败有可见短提示和无障碍播报。关联 CI-REG-015～018；本次为布局偏好，不新增缺陷编号。

## 自动检查

- `previewHeader.test.ts` 检查标题／路径去重、Windows 分隔符、目标行号、实际浏览器头部脚本的安全文本更新、加载／错误／完成状态和按钮聚焦局部滚动。
- `codePreview.test.ts` 保留初始缓冲、滚轮回放、元数据局部更新和预览所有权接线检查；`previewRange` 与 `previewColors` 保留范围及主题配色回归。
- `suite/previewHeader.ts` 在真实 VS Code 原生 Webview 和实际组合 iframe 中检查单行布局、初始目标可见、元数据不重建源码、加载失败不挤动代码、前插源码后的锚点及横向位置、窄栏按钮聚焦。使用合成文档和拒绝语义查询的受控服务，不读取业务工程。
- 单行专项在 `runCombinedViewTest` 的完整入口中自动执行；也可单独运行：

```bash
npm run check
C_INSIGHT_PREVIEW_HEADER_ONLY=1 C_INSIGHT_VSCODE_EXECUTABLE_PATH=/path/to/test/code xvfb-run -a node dist/test/e2e/runCombinedViewTest.js
```

## 人工重点

1. 独立及组合视图分别预览定义、声明、引用和调用点，核对类型、有效标题、文件名及目标行号。文件路径作为标题时不重复显示；头部悬停能查看完整位置。
2. 在宽／窄栏、底部面板、深浅及高对比度主题下核对单行高度、文本省略、按钮可访问性和焦点提示；Tab 到按钮仅滚动其所在工具栏，不拉动代码或组合视图。
3. 新目标首次滚轮即生效，目标按 `linesBefore` 定位；加载前后没有闪回。信息图标包含已加载范围及文件边界，头部目标行号不随滚动改变。
4. 连续向上／下加载、达到行数预算后裁剪再加载，核对可见源码和横向位置；加载、失败及恢复均不增加一行或移动代码区。检查首次响应和减少动态效果。
5. 滚动后等待同目标的详情更新，再切换配色及使用预览历史，确认内容、选区和滚动不被元数据更新重置。历史、锁定、复制代码、复制路径及打开编辑器的目标保持不变。
6. 在实际 WSL／SSH 环境验收鼠标、原生提示和屏幕阅读器播报，记录使用的临时包与主题。
